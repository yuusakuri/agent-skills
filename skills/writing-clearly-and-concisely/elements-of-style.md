## I. はじめに

この手引きは、平明な英語の文章作法の要点をまとめたものである。特に破られやすい語法と構成の原則に焦点を当て、網羅的な手引きに代わる簡潔な指針を示す。ここで扱う指針を身につけたら、優れた書き手から、さらに細かな文章作法を学ぶ。

## III. 文章構成の原則

### 原則8. 段落を構成の単位にし、1段落で1話題を扱う

扱う主題の範囲が狭い場合や、ごく短く扱う場合は、話題を細分化する必要がないこともある。短い描写、文学作品の短い要約、1つの出来事の簡潔な説明、動作の筋だけを述べる物語、1つの考えの提示は、それぞれ1段落で書くのがよい。段落を書いたら、分割するとよくなるかを確認する。

ただし通常は、主題を話題ごとに分け、それぞれを段落の主題にする必要がある。話題ごとに段落を分ける目的は、読者の理解を助けることにある。段落の始まりは、主題の展開が次の段階へ進んだことを知らせる。

分割の細かさは、文章の長さによって変わる。たとえば書籍や詩の短い紹介なら、1段落で足りることがある。少し長い紹介なら、次の2段落にできる。

- A. 作品の紹介。
- B. 批評。

文学の授業で書く詩の報告なら、7段落にできる。

- A. 執筆と出版に関する事実。
- B. 詩の種類と韻律の形式。
- C. 主題。
- D. 主題の扱い方。
- E. 特に注目すべき点。
- F. 作者らしさが表れている点。
- G. 他の作品との関係。

CとDの内容は、詩によって変わる。通常、Cでは、説明が必要なら詩の現実または想像上の状況を示し、主題とその展開の概要を述べる。全編が三人称の物語である場合は、出来事の簡潔な要約だけでよい。Dでは、中心的な考えと、それを際立たせる方法を示すか、物語の中で特に強調されている点を示す。

小説は、次の項目で論じられる。

- A. 舞台。
- B. 筋。
- C. 登場人物。
- D. 目的。

歴史上の出来事は、次の項目で論じられる。

- A. 出来事に至る経緯。
- B. 出来事の説明。
- C. 出来事がもたらした結果。

最後の2つの主題を扱う場合、書き手は挙げた項目の一部をさらに分ける必要があるだろう。

原則として、1文だけで段落を作らない。ただし、説明や議論の各部分の関係を示すつなぎの文は、例外にできる。多くの話題を短く扱う教科書、案内書などでも、例外がしばしば必要になる。

会話では、発言が1語だけでも、発言ごとに段落を分ける。つまり、話者が変わるたびに段落を改める。会話と地の文が混在する場合の適用方法は、適切に組版された小説の例から学ぶのがよい。

### 原則9. 原則として主題文で段落を始め、冒頭に対応する形で終える

ここでも目的は読者の理解を助けることである。この書き方なら、読者は段落を読み始めたときにその目的を把握し、読み終わるまで覚えていられる。そのため、特に説明や議論で広く役立つ段落は、次の形を取る。

(a) 主題文が冒頭、または冒頭近くにある。

(b) 続く文が、主題文の内容を説明、立証、展開する。

(c) 最後の文が、主題文の考えを強調するか、重要な帰結を述べる。

脱線や重要でない細部で終えることは、特に避ける。

段落が長い文章の一部である場合は、前の部分との関係や、全体の中での役割を示す必要があるかもしれない。主題文の「また」「したがって」「同じ理由で」などの語句だけで示せることもある。一方、主題文の前に導入や移行の文を置くほうがよい場合もある。移行に複数の文が必要なら、通常は独立した段落にするほうがよい。

段落の本文と主題文の結び付け方は、目的に応じて選べる。主題文を別の形で言い直す、用語を定義する、反対の主張を否定する、具体例を示すなどして、意味を明確にできる。証拠で立証することも、含意や帰結を示して展開することもできる。長い段落では、いくつかを組み合わせられる。

1 徒歩旅行を十分に楽しむには、1人で出かけるべきだ。2 集団や2人連れで行けば、徒歩旅行とは名ばかりで、むしろピクニックに近い別のものになる。3 徒歩旅行は1人でするべきだ。自由が本質であり、気の向くまま立ち止まり、進み、こちらやあちらの道を選べなければならず、自分の歩調を保ち、健脚の人に合わせて小走りしたり、少女に合わせて小刻みに歩いたりする必要があってはならないからだ。4 そして、あらゆる印象を受け入れ、見たものが思考を彩るに任せる必要がある。5 どんな風にも鳴る笛のようであるべきだ。6 Hazlittは「歩きながら話すことのどこが気が利いているのか分からない」と言う。7 「田園にいるときには、田園のようにただ生きていたい。」この言葉が、この問題について言えることの要点を示している。8 朝の瞑想的な静けさを乱す話し声が、すぐそばにあってはならない。9 思考を論理的に進めている間は、屋外で十分に体を動かすときの心地よい陶酔に身を任せられない。その陶酔は、頭のくらみや鈍さのような感覚から始まり、理解を超えた安らぎへ至る。Stevenson『Walking Tours』。

1 主題文。2 反対の場合を否定して意味を明確にする。3 主題文を短く繰り返し、3つの理由で支える。3番目の理由である「自分の歩調を保つ」は、反対の場合を否定して明確にする。4 4番目の理由を2つの形で述べる。5 同じ理由をさらに別の形で述べる。6〜7 同じ理由をHazlittの言葉で述べる。8 Hazlittの引用を言い換えて繰り返す。9 4番目の理由を最後に述べ、表現を広げ、高めて、力強い結びにする。

1 歴史に関する大きく異なる考え方が育ったのは、主に18世紀である。2 歴史家は、自らの仕事を、絵を描くことより問題を解くこと、つまり国家の成長、繁栄、逆境の各段階を説明し、明らかにすることだと考えるようになった。3 道徳、産業、知性、芸術の歴史、習慣や信念の変化、各時代を支配した考え、政治体制の成立、崩壊、変容、要するに国家の幸福に関わるすべての条件が、研究の対象となった。4 王の歴史より、国民の歴史を書こうとした。5 特に歴史の中に、原因と結果の連鎖を求めた。6 過去における国家の生理を研究し、実験的方法を大規模に適用することで、社会の幸福を主に左右する条件について、実際に価値のある教訓を導こうとした。Lecky『The Political Value of History』。

1 主題文。2 主題文の意味を明確にし、新しい歴史観を定義する。3 定義を広げる。4 対比で定義を説明する。5 新しい歴史観の別の要素を示し、定義を補う。6 結論として、新しい歴史観の重要な帰結を示す。

物語や描写では、後に続く細部をまとめる、簡潔で全体を捉えた文から段落を始めることがある。

そよ風は、私たちにとって実に都合がよかった。

作戦は、敗北の連続で始まった。

続く10〜12ページは、奇妙な記録で埋め尽くされていた。

ただし、多用すると型にはまった表現になる。より一般的には、冒頭の文の主語によって、段落の主な対象を示すだけである。

ようやく私は、柵のほうへ戻ってもよいと思った。

彼は重いランプを机から持ち上げ、探索を始めた。

さらに階段を1つ上ると、彼らは屋上に出た。

ただし、動きのある物語の短い段落には、主題文らしい文さえないことが多い。その段落の区切りは、表現上の間を作り、動作のある細部を際立たせる。

### 原則10. 能動態を使う

通常、能動態は受動態より直接的で力強い。

私は、初めてBostonを訪れたときのことを、いつまでも覚えているだろう。

これは、次の文よりはるかによい。

私の初めてのBoston訪問は、私によっていつまでも記憶されるだろう。

後者は、直接性、力強さ、簡潔さで劣る。「私によって」を省いて短くしようとすると、次のようになる。

私の初めてのBoston訪問は、いつまでも記憶されるだろう。

これでは、いつまでも覚えているのが書き手なのか、示されていない誰かなのか、世間一般なのか分からない。

もちろん、この原則は受動態を完全に捨てることを意味しない。受動態は便利なことが多く、必要な場合もある。

王政復古期の劇作家は、今日ではあまり評価されていない。

現代の読者は、王政復古期の劇作家をあまり評価しない。

王政復古期の劇作家を扱う段落なら前者が、現代の読者の趣味を扱う段落なら後者が適切である。この例のように、特定の語を主語にする必要によって、どちらの態を使うかが決まることが多い。

動作全体を名詞で表して受動態の主語にし、動詞には文を終える役割しか残さない書き方は、よくある欠点である。

| 原文の例 | 書き換え例 |
| --- | --- |
| この地域の調査が1900年に行われた。 | この地域は1900年に調査された。 |
| 軍の動員が迅速に実施された。 | 軍は迅速に動員された。 |
| これらの報告の確認は得られない。 | これらの報告は確認できない。 |

「金の輸出は禁止された」という文と比べる。この文の述語「禁止された」は、「輸出」自体には含まれていない内容を表す。

能動態を日常的に使うと、力強い文章になる。これは、動作が中心の物語だけでなく、あらゆる文章に当てはまる。「〜がある」「〜が聞こえた」のような役割の薄い表現を能動態の動詞に置き換えると、弱い描写や説明が生き生きとし、要点が際立つ。

| 原文の例 | 書き換え例 |
| --- | --- |
| 地面には、多くの枯れ葉が落ちていた。 | 枯れ葉が地面を覆っていた。 |
| 家のどこかでギターの音が聞こえた。 | 家のどこかでギターが眠たげに響いていた。 |
| 彼が大学を辞めた理由は、健康を損なったことだった。 | 健康の悪化によって、彼は大学を辞めざるを得なかった。 |
| 彼は、自分が言ったことを、まもなくひどく後悔するようになった。 | 彼はすぐに自分の言葉を悔いた。 |

### 原則11. 肯定の形で述べる

明確に主張する。弱く、特徴がなく、ためらいがちで、態度の定まらない表現を避ける。否定は、否認や対比のために使い、言い逃れに使わない。

| 原文の例 | 書き換え例 |
| --- | --- |
| 彼は、あまり時間どおりには来なかった。 | 彼は、たいてい遅れて来た。 |
| 彼は、ラテン語の勉強があまり役に立つとは思わなかった。 | 彼は、ラテン語の勉強を無益だと思った。 |
| 『じゃじゃ馬ならし』には、やや弱い箇所がある。ShakespeareはKatharineをあまり立派な人物として描いておらず、BiancaもShakespeareの作品の重要な人物として長く記憶に残るわけではない。 | 『じゃじゃ馬ならし』の女性たちは魅力に欠ける。Katharineは不愉快で、Biancaは存在感が薄い。 |

最後の例の原文は、否定的なだけでなく不明確である。そのため、書き換え例は書き手の意図を推測したものにすぎない。

3つの例はいずれも、否定表現に伴う弱さを示す。読者は意識的であれ無意識的であれ、「何でないか」だけを知らされることに満足せず、「何であるか」を知りたがる。そのため通常は、否定する内容も肯定の形で表すほうがよい。

| 原文の例 | 書き換え例 |
| --- | --- |
| 正直ではない | 不正直だ |
| 重要ではない | 些細だ |
| 覚えていなかった | 忘れた |
| 注意をまったく払わなかった | 無視した |
| あまり信頼していなかった | 疑っていた |

否定と肯定の対比には力がある。

慈善ではなく、単に正義である。

Caesarへの愛が弱かったのではなく、Romeへの愛がより強かったのだ。

単純な「〜でない」以外の否定語は、通常、力がある。

英国旗に日は決して沈まない。

### 原則12. 明確で、個別的で、具体的な言葉を使う

一般的な表現より個別的な表現を、曖昧な表現より明確な表現を、抽象的な表現より具体的な表現を選ぶ。

| 原文の例 | 書き換え例 |
| --- | --- |
| 天候が悪い時期に入った。 | 1週間、毎日雨が降った。 |
| 彼は、働きに見合う報酬を手にして満足を示した。 | 彼は、硬貨をポケットに入れながらにやりと笑った。 |
| 波乗りの経験を楽しんだ人々の間では、波乗りが大きな高揚感をもたらすという一般的な合意がある。 | 波乗りをした人は皆、とても爽快だという点で一致する。 |

文章の技術を学んだ人々が一致する点があるとすれば、読者の注意を引き、保つ最も確実な方法は、個別的、明確、具体的に書くことだという点である。批評家は、Homer、Dante、Shakespeareのような偉大な書き手の力が、絶えず明確で具体的に書くことに大きく由来すると指摘している。より近代の作者であるBrowningにも、印象的な例が多い。たとえば『My Last Duchess』の次の箇所がある。

あの女には、どれも同じだったのです。胸元につけた私の贈り物も、

西へ沈む日の光も、

おせっかいな愚か者が果樹園で折って渡した

さくらんぼの枝も、白いラバに乗って

テラスを巡ることも、すべて同じように、

褒め言葉を引き出し、

少なくとも頬を赤らめさせたのです。

詩の結びにもある。

ですが、あのNeptuneをご覧ください。

海馬を手なずける、珍しいとされる像です。

InnsbruckのClausが、私のために青銅で鋳造したものです。

これらの言葉は情景を呼び起こす。『The Bishop Orders his Tomb in St. Praxed's Church』で、Ruskinの評する「ルネサンスの精神、その世俗性、矛盾、誇り、偽善、自己への無知、芸術、贅沢、優れたラテン語への愛」が、個別の細部と具体的な言葉でどのように示されているかを思い出してほしい。

散文、特に物語や描写も、同じ方法で生き生きとする。Jim Hawkins、David Balfour、Kim、Nostromoの経験が、無数の読者に一時でも現実のように感じられたのなら、Carlyleを読んでBastille襲撃の場に自分もいるかのように感じるのなら、それは細部が明確で、言葉が具体的だからである。すべての細部を書くということではない。それは不可能であり、目的にもかなわない。重要な細部をすべて、曖昧にせず、読者が想像の中でその場面に身を置けるほど明確に示すということである。

説明や議論でも、具体性を失ってはならない。一般原則を扱うときにも、その適用例を示す必要がある。

「個別的な表現が優れる理由は、言葉を思考に変換する労力にある。私たちは一般的なものではなく、個別的なものを使って考える。ある種類のものに言及されると、その種類の個々のものを思い浮かべる。したがって、抽象語が使われると、聞き手や読者は、自分の記憶にある像から、その種類を思い描くためのものを1つ以上選ぶ必要がある。この作業には時間と労力がかかる。個別的な語によって適切な像をすぐに示せれば、その負担を減らし、より鮮明な印象を生める。」

この段落の引用元である『Philosophy of Style』で、Herbert Spencerは次の文を使って原則を説明している。

| 原文の例 | 書き換え例 |
| --- | --- |
| 国民の作法、習慣、娯楽が残酷で野蛮になるほど、刑法の規定は厳しくなる。 | 戦闘、闘牛、剣闘士の戦いを喜ぶほど、人々は絞首刑、火刑、拷問台で罰するようになる。 |

### 原則13. 不要な語を省く

力強い文章は簡潔である。絵に不要な線を描かず、機械に不要な部品を付けないのと同じ理由で、文には不要な語を、段落には不要な文を含めない。これは、すべての文を短くしたり、細部を避けて主題の概要だけを書いたりすることではない。すべての語に意味のある役割を持たせるということである。

よく使われる表現にも、この原則に反するものが多い。

| 原文の例 | 書き換え例 |
| --- | --- |
| 〜かどうかということに関する問題 | 〜かどうか（〜かどうかという問題） |
| 〜であることに疑いはない | 疑いなく |
| 燃料の目的で使われる | 燃料に使われる |
| 彼は〜する人である | 彼は〜する |
| 性急な方法で | 性急に |
| これは〜という主題である | この主題 |
| 彼の話は奇妙なものである。 | 彼の話は奇妙である。 |

特に「〜という事実」は、それを含む各文を見直して取り除く。

| 原文の例 | 書き換え例 |
| --- | --- |
| 〜という事実のために | 〜なので |
| 〜という事実にもかかわらず | 〜ではあるが |
| 〜という事実に注意を向ける | 〜を思い出させる（知らせる） |
| 〜という事実を知らなかった | 〜と知らなかった |
| 彼が成功しなかったという事実 | 彼の失敗 |
| 私が到着したという事実 | 私の到着 |

「〜である」「〜だった」などの説明も、不要なことが多い。

| 原文の例 | 書き換え例 |
| --- | --- |
| 同じ会社の一員である彼の兄 | 同じ会社の一員、彼の兄 |
| Nelsonの最後の戦いだったTrafalgar | Nelsonの最後の戦い、Trafalgar |

肯定文は否定文より、能動態は受動態より簡潔なので、原則11と12の例の多くは、この原則も説明している。

1つにまとめるほうがよい複雑な考えを、複数の文や独立した節に分けて少しずつ述べることも、簡潔さを損なうよくある例である。

| 原文の例 | 書き換え例 |
| --- | --- |
| Macbethは非常に野心的だった。そのためScotlandの王になりたいと思った。魔女たちは、その願いがかなうと告げた。当時のScotlandの王はDuncanだった。妻に励まされ、MacbethはDuncanを殺した。その結果、Duncanの後を継いで王になることができた。（英語原文51語。） | 妻に励まされ、MacbethはDuncanを殺してScotlandの王になり、野望を達成するとともに魔女たちの予言を実現した。（英語原文26語。） |
| 重要度の低い科目はほかにもあったが、これらが最も重要で、毎日ではないにせよ、次に何をすることになるのか分からない気持ちにさせるほど頻繁にあった。（英語原文43語。） | 最も重要なこれらの科目は、毎日ではないにせよ、絶えず緊張させるほど頻繁にあった。（英語原文21語。） |

### 原則14. 付け足し型の文を続けない

この原則が特に対象とするのは、独立した2つの節を並べ、後の節を接続表現でつなぐ種類の、付け足し型の文である。その形の文自体に問題がなくても、続くとすぐに単調で退屈になる。

未熟な書き手は、「そして」「しかし」「だから」などの接続表現や、時間、場所、対象について補足する表現を使い、段落全体をこの種類の文だけで構成することがある。

定期演奏会の第3回が昨晩開かれ、多くの聴衆が訪れた。Edward Appleton氏が独奏者を務め、Boston Symphony Orchestraが器楽を担当した。前者は第一級の芸術家であることを示し、後者は高い評価に十分ふさわしいことを証明した。この演奏会への関心は委員会にとって大変喜ばしく、今後は同様の演奏会を毎年開く計画である。第4回は5月10日火曜日に開かれ、同じように魅力的な演目が披露される。

上の段落は、陳腐で内容が薄いことに加え、文の構造が機械的に対称で、単調な調子になっているため弱い。原則9で引用した段落や、『Vanity Fair』の序文「Before the Curtain」など、優れた英語の散文と比べてほしい。

この形の文を続けて書いていたら、単調さがなくなるだけの文を書き直す。単文、密接な関係のある2つの節からなる文、最後に主要な意味が確定する2つの節からなる文、3つの節からなる付け足し型または文末で意味が確定する文など、実際の考えの関係を最もよく表す形式を選ぶ。

### 原則15. 並列する考えは、似た形式で表す

並列構造の原則では、内容と役割が似た表現は、外形も似せる。形式が似ていれば、読者は内容と役割の類似性を認識しやすい。聖書の十戒、至福の教え、主の祈りの願いは、よく知られた例である。

未熟な書き手は、表現形式を絶えず変えるべきだと誤解し、この原則を破りがちである。強調のために同じことを繰り返すときには、形式を変える必要がある場合もある。原則9のStevensonの段落がその例である。それ以外では、並列構造の原則に従う。

| 原文の例 | 書き換え例 |
| --- | --- |
| 以前、科学は教科書方式で教えられていたが、現在は実験室方式が用いられる。 | 以前、科学は教科書方式で教えられていた。現在は実験室方式で教えられている。 |

左の文は、書き手が迷っている、あるいはためらっている印象を与える。1つの表現形式を選んで保てない、またはそれを恐れているように見える。右の文では、少なくとも形式を選び、それに従っていることが分かる。

原則12の3番目の例と、原則13の最後の例も参照する。

同じ種類の考えを20個も表す必要がある場合は、同じ形の文を20回続けるべきなのかという疑問が生じるかもしれない。詳しく見れば、その難しさは思い込みで、20個の考えをいくつかの集まりに分け、各集まりの中でだけ原則を適用すればよいことが多い。それができなければ、表にして難しさを避けるのがよい。

### 原則16. 関係する語を近くに置く

文中の語の位置は、その関係を示す主な手段である。したがって、意味の上で関係する語や語句をできるだけ近くに置き、関係しないものを離す。

原則として、文頭へ移せる語句や節を、主語と主要な述語の間に挟まない。

| 原文の例 | 書き換え例 |
| --- | --- |
| Wordsworthは、『The Excursion』の第5巻で、この教会を詳しく描写している。 | 『The Excursion』の第5巻で、Wordsworthはこの教会を詳しく描写している。 |
| 鋳鉄は、Bessemer転炉で処理されると、鋼に変わる。 | Bessemer転炉で処理することで、鋳鉄は鋼に変わる。 |

問題なのは、挿入した語句や節が、主な文の自然な順序を不必要に中断することである。ただし、短い補足や同格の説明だけを挟む場合には、通常、この問題は生じない。また、最後まで主要な意味を確定させず、意図的に期待を持たせる文にも当てはまらない。原則18の例を参照する。

修飾語は、可能なら修飾される語の隣に置く。複数の表現が同じ語を修飾する場合は、誤った関係を示さないように並べる。

| 原文の例 | 書き換え例 |
| --- | --- |
| 全員は出席していなかった。 | 全員が出席していたわけではなかった。 |
| 彼は2つの間違いを見つけただけだった。 | 彼が見つけた間違いは2つだけだった。 |
| R. E. Joyce少佐が火曜の夜にBailey Hallで、一般の方も招待する講演を、「私のMesopotamiaでの経験」について午後8時に行う。 | 火曜午後8時、R. E. Joyce少佐がBailey Hallで「私のMesopotamiaでの経験」と題した講演を行う。一般の方も参加できる。 |

### 原則17. 要約では対象の内容に集中する

随筆の要約や講演の報告など、他者の発言や考えを紹介する場合は、「彼は言った」「彼は述べた」「講演者は付け加えた」「続けて述べた」「著者はまた考えている」などを挟まない。冒頭で、これから示す内容が要約であることを一度明確にすれば、繰り返し知らせるために言葉を費やす必要はない。

ノート、新聞、文学の手引きでは、要約が欠かせない場合がある。小学生が物語を自分の言葉で語り直すことも、有用な練習である。ただし、文学の批評や解釈を書くときは、要約に流れないようにする。作品の主題や冒頭の状況を示すために1〜2文を使ったり、特徴を示すために細部を多く挙げたりする必要はあるだろう。それでも目指すべきは、ところどころにコメントを付けた要約ではなく、根拠に支えられた秩序ある議論である。複数の作品を扱う場合も、通常は年代順に1つずつ取り上げるより、最初から全体に関わる結論を示すことを目指すほうがよい。

### 原則18. 強調する語を文末に置く

最も目立たせたい語や語句を置くのに適した位置は、通常、文末である。

| 原文の例 | 書き換え例 |
| --- | --- |
| 人類は、あの時代から忍耐力ではほとんど進歩していないが、ほかの多くの点では進歩した。 | 人類は、あの時代からほかの多くの点では進歩したが、忍耐力ではほとんど進歩していない。 |
| この鋼は主に剃刀の製造に使われる。その硬さのためである。 | この鋼は硬いため、主に剃刀の製造に使われる。 |

この目立つ位置に置かれるものは、通常、論理上の述部、つまり2番目の例のように、その文で新しく示される要素である。

文末で主要な意味が確定する文が効果的なのは、中心となる内容を際立たせるためである。

4世紀前、自国の共和国の衰退によって世界と冒険に身を投じたイタリアの船乗りの1人、Christopher Columbusは、Portugalの探検家の成果に対抗するため、SpainのためにIndiesへの西回り航路を探し、Americaに行き当たった。

この希望と信念をもって、私はあなたが、あらゆる障害を退け、私的な目的を捨て、揺らがず、ひるまず、この戦争を力強く、成功裏に遂行することへ身を捧げるよう強く求める。

文中でもう1つ目立つ位置は、冒頭である。主語以外の要素は、最初に置くと強調できる。

欺瞞や裏切りを、彼は決して許せなかった。

非常に巨大で粗く、約3千年にわたる作用によって刻まれたこの建築の断片は、一見、自然の造形のように見えることがある。

文頭の主語が強調されることもあるが、位置だけが理由になることはほとんどない。次の文では、

偉大な王たちが、彼の聖所で礼拝した。

「王たち」の強調は、主にその意味と文脈によって生じる。主語を特に強調するには、述部の位置へ置く必要がある。

谷の中央を流れていたのは、曲がりくねった小川だった。

最も目立たせたいものを最後に置く原則は、文中の語、段落中の文、文章中の段落のいずれにも当てはまる。
